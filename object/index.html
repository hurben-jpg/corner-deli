Every OBJECT exists for a limited time.

Sometimes an object leaves because someone decides it is worth owning.

Sometimes it leaves because its time has expired.

Either way, the room becomes empty.

Then another OBJECT arrives.

About OBJECT

OBJECT is a proposed cultural institution exploring the presentation of extraordinary objects.

Its subjects may include sculpture, design, geology, archaeology, natural history, craft or things that resist classification altogether.

Each OBJECT occupies the room alone.

The room asks only one thing:
Look.

Departure

Most OBJECTs begin at an intentionally ambitious value.

Their price gradually descends over time.

Eventually someone decides that moment has arrived.

The OBJECT departs.

Another OBJECT takes its place.

On Loan

Not every OBJECT is available for acquisition.

Some are presented for a limited period before returning to their owner.

When an OBJECT is on loan, the display replaces the price with a countdown until its departure.

This allows rare, borrowed or irreplaceable objects to become part of the programme while preserving the same ritual.

Western Australian objects

The first OBJECTs are being developed using jarrah, terrazzo and brass.

Future OBJECTs may emerge from many disciplines and materials.

Selection is determined not by category, but by significance.

The Window

The room remains visible day and night.

One OBJECT.

One display.

Nothing else competes for attention.
