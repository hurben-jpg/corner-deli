# Corner Deli

Corner Deli is the public website and curatorial host for independent projects. It is not the source workspace for those projects.

## Public routes

- `/identity-tapestry/` — published output from the sibling Identity Tapestry project
- `/erebor/` — public clients for the sibling Erebor project
- `/object/` — published presentation of the sibling OBJECT project

Shared navigation, brand assets, favicons, hosting configuration, and the project index belong here. High-resolution working brand material is kept locally in `source-assets/` and excluded from production commits.

This directory preserves the original Corner Deli Git history and deploys directly through Netlify.
